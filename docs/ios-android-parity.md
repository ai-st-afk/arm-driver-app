# Сверка веб-версии с Android · 2026-11-18

Источник для сравнения — `android/app/src/main/java/ru/profstroyservices/armdriver/ui/`, `AssignmentState.kt`, `AssignmentRepository.kt`, `QueueRepository.kt` и контракт `architecture.md`. Веб работает через тот же Go-шлюз и XML-контракт 1С.

| Сценарий | Веб-версия после сверки |
|---|---|
| Первый запуск | «Телефон не настроен» → «Служебный вход», как Android. |
| Привязка | Тот же QR водителя из 1С: один GUID и ФИО; ручной GUID как запасной способ. Кнопки выхода у водителя нет; перепривязка — на служебном экране. |
| Разнарядки | Список по дням с текущей первой; одна разнарядка открывается сразу. №36 «Заменена» остаётся для справки, №37 становится текущей без ожидания закрытия смены №36. Устаревшие версии не применяются; пропавшие ездки остаются снятыми. |
| Ознакомление и смена | Разнарядка видна накануне; начало смены — только в день выезда и после выдачи ключей. При замене машины используются признаки смены из 1С. При изменении маршрута нужно новое ознакомление; при версии только с выдачей ключей оно отправляется автоматически. Кнопки завершения смены нет. |
| Рейсы | Текущая разнарядка, этапы по GUID и порядку 1С, первый доступный рейс раскрыт. Показаны смена адреса разгрузки, возврат, груз в машине, прицеп, контакты, адреса, план и факты, отменённые и сорванные ездки. |
| «Не могу выполнить рейс» | Причина и комментарий, после прибытия на разгрузку — коды отказа клиента; качество требует фото груза, «Прочее» — комментарий. Рейс остаётся до решения диспетчера. |
| Фото | Грузовик сзади и сбоку при загрузке, те же снимки и документ при разгрузке; превью, пересъёмка, дополнительные листы, обязательная причина при недостающих снимках. |
| Очередь и история | GUID и время — в момент действия; 5 секунд на отмену этапа без фото; отмена локального этапа с фото до отправки; поштучный ответ 1С, видимая очередь и ошибки, повторная отправка. История показывает геометку и отменённые действия. |
| Настройки и уведомления | Водитель, машина, звонок диспетчеру, версия, проверка обновления, служебный вход. Web Push требует установки на экран «Домой» и разрешения iOS. |

Проверено локальными JS- и Go-тестами, включая выбор новой разнарядки, снятую ездку, перенаправление после срыва, раздельные сессии и поштучный ответ 1С. Камера, геометка, Web Push и сохранность IndexedDB после выгрузки процесса ещё требуют проверки на физическом iPhone. Системные окна iOS и установка PWA отличаются от Android по правилам платформы.
